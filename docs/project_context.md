# Konteks Bisnis: Kost Point

Kost Point adalah aplikasi pencarian kos mahasiswa berbasis kalkulasi jarak otomatis dan ketersediaan kamar real-time.

## Masalah yang Diselesaikan

1. Mahasiswa Rantau: Kesulitan mengenal rute wilayah kampus, lelah survei keliling gang, sering terkecoh jarak lisan yang jauh/macet menuju gerbang kampus, dan sering mendapati kamar sudah penuh saat tiba di lokasi.
2. Pemilik Kos: Promosi manual terbatas (spanduk/sosmed), lelah membalas chat WhatsApp berulang kali untuk pertanyaan harga dan sisa kamar, serta tidak punya catatan terpusat untuk memantau kamar kosong/terisi.

## Target Pengguna (Satu Aplikasi - Multi Role)

1. Mahasiswa, siswa, pekerja kantoran (Pencari Kos)
2. Pemilik Kos (Admin Kos)
