# UI Guidelines - Kost Point

## 1. Color Palette

- Primary Color: #0056A0 (Biru Kampus - untuk AppBar, tombol utama, dan elemen aktif)
- Secondary/Accent (Premium): #FFC107 (Kuning Emas - khusus untuk badge "Pro/Direkomendasikan", border card kos premium, dan ikon bintang rating)
- Background Color: #F8F9FA (Abu-abu sangat terang untuk latar belakang layar)
- Surface/Card Color: #FFFFFF (Putih bersih untuk kartu kos dan bottom sheet)
- Text Primary: #212529 (Hitam keabu-abuan untuk judul dan teks utama)
- Text Secondary: #6C757D (Abu-abu medium untuk teks jarak, alamat, dan keterangan)
- Status Available: #198754 (Hijau untuk indikator kamar masih tersedia)
- Status Full: #DC3545 (Merah untuk indikator kamar penuh)

## 2. Tipografi & Komponen

- Font: Google Fonts `Plus Jakarta Sans` atau `Poppins`.
- Card Kos: Border radius `16px`, elevasi tipis (`elevation: 2` dengan shadow opacity rendah). Khusus Card Kos Premium, tambahkan border tipis berwarna `#FFC107` (width `1.5px`) dan badge "PRO / Teratas".
- Tombol: Border radius `12px`, tinggi minimal `48px` agar nyaman disentuh di layar HP.
